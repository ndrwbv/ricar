# Рыцарь

Ультранасильственный FPS в духе раннего Doom и Brutal Doom. Сейчас в репозитории один уровень —
**песочница**: зал-склеп с галереей и зал-зверинец, где у каждого вида врага своя комната, а прямо
напротив точки появления — пещера.
Сюжетные уровни («Возвращение», «Чужой город», перенос E1M1) убраны; новые делаются в редакторе.

* Гейм-дизайн документ: [docs/GDD.md](docs/GDD.md)
* Технические решения, производительность на Steam Deck, почему не Godot: [docs/TECH.md](docs/TECH.md)
* Установка и запуск на Steam Deck: [docs/DECK.md](docs/DECK.md)
* Как нарисовать своих врагов и настроить их анимации/поведение: [docs/ENEMIES.md](docs/ENEMIES.md) — файлы в `public/enemies/`

## Установка на Steam Deck

Перейти в десктоп-режим (зажать **STEAM** → `Power` → **Switch to Desktop**), открыть **Konsole**,
перейти туда, где должна лежать игра (например `cd ~`), и выполнить одну команду:

```bash
curl -fsSL https://raw.githubusercontent.com/ndrwbv/ricar/main/tools/install-deck.sh | bash
```

Скрипт качает свежий релиз, распаковывает игру в папку `knight` **в текущем каталоге**, проставляет
права на запуск и делает ярлык «Рыцарь» на рабочем столе и в меню приложений. Запуск — `./knight/knight.sh`
(`--windowed` — окном вместо полного экрана). Обновление — та же команда: прошлая установка перезаписывается,
уровни из редактора лежат отдельно (`~/.config/Knight/levels`) и не страдают.

Флаги — после `| bash -s --`, например `| bash -s -- --run`:

| Флаг | Что делает |
| --- | --- |
| `--run` | запустить игру сразу после установки |
| `--dir ПАПКА` | поставить не в `./knight`, а куда сказано |
| `--tag v0.1.0` | конкретная версия вместо последней |
| `--no-desktop` | не создавать ярлык |

Чтобы играть из игрового режима: Steam → **Games → Add a Non-Steam Game → Browse** → фильтр **All Files** →
`knight.sh` из папки установки → в свойствах ярлыка **не** включать Proton (сборка нативная под Linux).

Сборки лежат в [релизах](https://github.com/ndrwbv/ricar/releases) и собираются вручную:
вкладка **Actions** → **Релиз для Steam Deck** → **Run workflow**. Локально на Mac то же самое — `npm run dist:deck`.
Раскладка геймпада, диагностика и подробности — [docs/DECK.md](docs/DECK.md).

## Запуск из исходников

```bash
npm install
npm run dev          # http://localhost:5173 — хаб
```

Хаб (`index.html`) — единая точка входа: список уровней с кнопками **Играть / Песочница / Редактор**, копирование,
экспорт и импорт уровней, и все настройки игры (картинка, управление, герой, враги, кровь, читы). Настройки и правки
уровней сохраняются автоматически; при запущенном dev-сервере редактор пишет уровни прямо в `public/levels/`.
Подробно: [docs/EDITOR.md](docs/EDITOR.md).

* `game.html?level=<id>&mode=play|sandbox` — игра; в песочнице **F1/`** панель (спавн, читы, время, телепорт), **F2** статистика, **F6** полёт, **F7** заморозка врагов.
* `editor.html?level=<id>` — редактор карт: примитивы, префабы, враги, предметы, NPC, триггеры и правила.
* Уровень один: `public/levels/sandbox.json` — **песочница**, герой бессмертен и носит весь арсенал (задаётся блоком `player` в JSON уровня). Герой появляется в зале-зверинце: перед ним ряд из девяти открытых комнат 10×12 м, в восьми возрождается свой вид врага, в девятой — **пещера**, и она ровно напротив точки появления. Через проход за спиной — зал-склеп с галереей на втором этаже. Остальные уровни удалены; новый создаётся кнопкой в хабе или копией песочницы.
* **Пещера** — префаб `cave`: коробка снаружи, внутри рваный контур из двух десятков коротких отрезков, каждый утоплен и поднят на случайную высоту, плюс сталагмиты, сталактиты, валуны и костры. Форма считается от `seed`, так что при перезагрузке она та же. Внутри спавнер с бегуньей.
* **Две руки**: меч всегда в левой, огнестрел в правой. **Tab** переключает — только меч, только ствол или **обе сразу**
  (тогда ЛКМ стреляет, ПКМ рубит, пинок переезжает на среднюю кнопку мыши).
* **Расчленёнка**: рука отлетает и вырезается из кадра, культя кровит, оружие и щит падают.
  **Ногу отстрелили — боец скачет на одной** (кадры `hop`), **обе — ползёт по земле** (`crawl`) и становится
  низкой, медленной целью. Меч в голову — шанс снести её начисто, отрубленная голова летит отдельным объектом.
  Зоны попадания задаются в `<name>.json` (`parts`) и пунктиром нарисованы в `<name>_template.png`.
* **Дробовик по дистанции**: в упор рвёт тело в клочья и забрызгивает потолок, на средней — противник улетает по дуге
  и шлёпается о землю, на дальней — обычное попадание.
* **Трупы простреливаются**: из груды летят куски мяса, пока она не «выработается».
* **Толпой не наваливаются.** Координатор боя (`Director` в `enemies.js`) собран из известных приёмов:
  «жетоны атаки» как в Halo — одновременно бьют только 2 бойца и стреляют 3 (настраивается);
  ротация нападающих как в Batman: Arkham — подержал жетон 6 секунд, уступи следующему;
  бронирование позиций как в F.E.A.R. — кольцо из 12 слотов вокруг игрока, двое в один не встают.
  Слоты разложены **дугой перед игроком**, а не полным кольцом: в спину не заходят и стеной не окружают.
  Вплотную не лезут — у игрока есть личное место, внутрь которого враги не входят. Подходят тем спокойнее,
  чем ближе, а вблизи ведут себя дёргано: подшагнуть, обойти боком, отскочить назад, замереть.
* **Враги**: прячутся за реальными укрытиями и приседают, сдаются (а иногда только делают вид — подпускают и бьют ножом),
  держат пост охраны вместо вечной погони (`guardR` у врага в редакторе).
* **Щит — отдельный PNG** (`public/enemies/shield.png`) со стадиями повреждения в ряд: держит заданное число
  ударов, на каждом меняет картинку (целый → помятый → треснувший → разбитый) и затем пропадает.
  Руку с собой не забирает, а вот **отстреленная рука роняет щит целиком**. Ловит только то, что им закрыто —
  голова, ноги и незакрытый бок получают обычный урон.
* **Трупы** — плоские спрайты в духе Doom (кадр `dead` того же листа), вокруг лужа, брызги и валяющиеся куски.
* Оружие в 3D (`src/engine/viewmodel3d.js`): меч с латной рукой, пистолет, дробовик (8 дробин, рвёт в упор), ракетница, сапог. Дробовик — готовая модель `public/models/shotgun.glb` (Quaternius, Ultimate Guns Pack, CC0, 746 треугольников; см. `public/models/CREDITS.md`). Положите свои `sword.glb`, `pistol.glb`, `shotgun.glb`, `rocket.glb` в `public/models/` — они подменят процедурные: ось, масштаб и место вспышки подбираются автоматически.
* **Ракетница** (`src/engine/rockets.js`): единственное оружие со снарядом. Ракета летит по прямой с дымным следом и взрывается о стену, пол, врага или на излёте; взрыв бьёт по площади (радиус 5.2 м), рвёт конечности, разбрасывает тела и задевает самого героя — на своём взрыве можно запрыгнуть на уступ. Клавиша 4, боезапас — `rockets`.
* **Второй этаж**: в редакторе есть выбор этажа, перекрытия (пол с флажком «по нему можно ходить») и префаб **Лестница**; высота этажа — в свойствах уровня.
* **Спавнер врагов** — префаб: бесконечные волны для дезматча, ставится куда угодно. В песочнице их три.
* Звук по умолчанию **выключен** (настройки → «Звук»). Музыки и шагов нет намеренно.
* **Свой враг добавляется без кода**: папка `public/enemies/<name>/` (`enemy.json` + `sheet.png` + его вещи в `drops/`) и имя в `index.json` —
  он сразу появляется в редакторе, спавнерах и песочнице. Так добавлен `knight_hard` — тёмный рыцарь 2.3 м
  с булавой и щитом.
* Враги — широкие листы 128×160 / 132×168 (в мире 1.44×1.8 и 1.49×1.9 м: плечистые туши, а не палки) с шаблонами-разметкой `public/enemies/<name>/template.png` для своих рисунков.
* Картинка — в духе **Bonehold**: у каждой зоны один доминирующий цвет, плотный туман, тяжёлые тени и постобработка (`src/engine/post.js`): контраст, тонирование теней в цвет зоны, виньетка, по желанию ступени цвета. Пресеты зон — `DEFAULT_ENVS` в `src/engine/levelloader.js`.
* В бою на экране **нет ни одной надписи**: слева внизу иконка здоровья с полосой, справа — иконка оружия и патроны гильзами. Ни сообщений, ни подсказок, ни счётчиков, ни анонсов убийств. Клавиши — в хабе.

```bash
npm run electron     # сборка и запуск в Electron
npm run dist:mac     # пакет для Steam (release/), аналогично --win / --linux
npm run dist:deck    # linux-x64 + release/knight-deck.tar.gz для Steam Deck (см. docs/DECK.md)
```

## Вылазка в пещеры

Бесконечный режим: `game.html?mode=cave` (кнопка «В пещеры» в хабе).
Стоишь на привале у скалы, заходишь в зев — пещера собирается заново: коридоры
и залы для разведки, широкая арена с мини-боссом и галереей под сводом, выход.
У каждого зала своя зона: бурый камень, серый известняк, чёрный выжженный грунт,
вросшая в камень техника, подземное озеро с водопадом, мшистый грот со столбами
света из дыр в своде. Из убитых вылетают крутящиеся пачки денег — подошёл,
и они присасываются к тебе; из стрелков падают их стволы. Нашёл выход — вышел,
показали итоги ходки, можно нырять снова; счётчик пройденных пещер растёт.
Начинаешь с одним мечом, стволы находишь в пещерах и уносишь с собой;
смерть обнуляет глубину, золото и оружие.

Правила, по которым собирается уровень, и клавиши отладки генерации (**M** — карта,
**F9** — пересобрать, **F10** — выгрузить JSON) — в [docs/CAVE.md](docs/CAVE.md).

## Импорт карт Doom

`tools/doom-import.mjs` переносит карту из WAD в наш формат уровня — геометрия один в один,
текстуры и враги подменяются нашими:

```bash
node tools/doom-import.mjs ~/DOOM1.WAD E1M1 doom-e1m1 "3. Ангар — Doom E1M1"
```

Так был сделан уровень `doom-e1m1` — настоящий E1M1 «Hangar»: 467 вершин, 475 линий, 85 секторов
и 138 вещей из WAD, в масштабе 1 юнит = 1/32 м (герой 56 юнитов = 1.75 м), карта 143×88 м.
Сам файл из репозитория убран вместе с остальными уровнями — команда выше соберёт его заново.

Как карта Doom ложится на движок без секторов:

* **стены** — линии WAD: односторонняя даёт стену от пола до потолка, двусторонняя — «ступень» снизу
  (разница полов) и «перемычку» сверху (разница потолков);
* **полы и потолки** — секторы растеризуются по BSP с шагом 8 юнитов (0.25 м) и склеиваются в
  прямоугольники `floor`; из них же получаются коллизия и ступеньки, а `stepUp: 0.78` в блоке `player`
  даёт герою думовский шаг в 24 юнита;
* **свет сектора** запекается в цвета вершин (`o.lit` у объекта) — десятки точечных источников роняли
  fps втрое, а картинка та же (для уровней, где источники всё же нужны, есть бюджет света — ниже);
* **двери** открыты навсегда: потолок дверного сектора поднимается до соседнего минус 4 юнита;
* **выход** — линия со спецэффектом 11 становится триггером `finish` перед выключателем;
* **вещи** берутся по сложности «ультранасилие»: зомби → `peasant`, сержант → `guard`, имп → `claw`,
  аптечки и броня → `health`, патроны и дробовик — как есть.

Чего нет: подвижных секторов (лифтов и опускающихся плит) и уроновых полов. Из-за лифтов два
секретных закутка E1M1 (зигзаг с кислотой за опускающейся плитой) остаются за стеной — пройти уровень
от старта до выхода это не мешает, тупиков-ловушек в карте нет (проверено обходом графа секторов).

WAD в репозиторий не кладётся: берите свой (shareware `DOOM1.WAD` распространяется свободно).
Геометрия уровней Doom принадлежит id Software — для своей игры в Steam нужна либо своя карта,
либо права.

## Управление

WASD — движение, мышь — обзор, Shift — рывок, Space — прыжок.
ЛКМ — удар мечом / выстрел, ПКМ — пинок (в режиме «обе руки» — удар мечом), средняя кнопка — пинок всегда, F — добить оглушённого (отрубить голову).
Tab — руки: меч → ствол → обе сразу. Q / колесо — сменить ствол, 1 / 2 / 3 / 4 — напрямую (меч, пистолет, дробовик, ракетница), R — перезарядка. По умолчанию носится одно огнестрельное (настройка «Сколько огнестрела носить»). Стрелки — поворот без мыши, P — размер пикселя, Esc — пауза.
В песочнице зажатый ⌘ / Ctrl отцепляет камеру и даёт облететь сцену: мышь вращает, колесо приближает, WASD/Space/E двигают точку обзора.
Геймпад / Steam Deck: левый стик — движение, правый — обзор, **RT — правая рука** (выстрел, в режиме меча — удар),
**LT — левая рука** (в режиме ствола тоже стреляет, в режиме меча и «обе руки» — удар клинком),
A — прыжок, B — рывок, X — перезарядка, Y — сменить ствол, LB — действие, RB — добить,
нажатие любого стика — пинок, крестовина — меч / пистолет / дробовик / ракетница (вверх / влево / вправо / вниз),
Select — режим рук, Start — пауза.

18+. Сцены крайней жестокости.

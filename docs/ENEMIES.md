# Как нарисовать своих врагов

## Добавить нового врага

1. Заведите ему папку `public/enemies/<name>/` — в ней лежит всё, что у него есть:

```
public/enemies/zombieman/
  enemy.json     ← главный файл: лист, анимации, статы, что из него выпадает
  sheet.png      ← лист спрайтов
  zones.png      ← разметка зон попадания (глазами, игрой не читается)
  drops/         ← его вещи: что остаётся после смерти
    clip.png
  gibs/          ← свои куски тела, если общих не хватает (необязательно)
```

2. Впишите имя в `public/enemies/index.json`:

```json
[ { "name": "peasant" }, { "name": "woman" }, { "name": "claw" },
  { "name": "guard" }, { "name": "knight_hard", "title": "Тёмный рыцарь" } ]
```

Код править не нужно: враг сам появится в редакторе, в спавнерах и в панели песочницы.
Если PNG или JSON не нашлись, враг просто пропускается (в консоли будет предупреждение).

Так сделан **`knight_hard`** — тёмный рыцарь с булавой и щитом: 10 кадров × 3 варианта,
136×188 px, в мире 1.66×2.30 м. Его лист собран из присланной картинки: фон убран,
кадры переставлены в порядке движка.

Последние три нарисованы кодом как заготовки под перерисовку: силуэты и роли разные,
чтобы поверх них было что рисовать. Забирайте `<имя>_template.png`, рисуйте свою графику
в границах кадров и кладите рядом как `<имя>.png` — код трогать не нужно.

`hound` — единственный не человек: у него нет рук (`"armL": null`), морда в профиль и всего
десять кадров. Он же показывает, как движок ведёт себя с неполным листом: сдачу, нож и
приседание он не умеет, а хромоту на трёх лапах и ползание — умеет, потому что кадры есть.

## Минимум кадров

Обязательны только `walk0` и `walk1` — всё остальное движок подставит сам:
нет `crouch` — не будет приседать, нет `hop`/`crawl` — **ноги не отрываются**
(боец не останется стоять на двух ногах с оторванной), нет `dead` — труп возьмёт
кадр по умолчанию. Руки отрываются всегда: они вырезаются из кадра маской.


Каждый враг — папка `public/enemies/<name>/`:

* `enemy.json` — раскладка листа, анимации, боевые настройки и его вещи;
* `sheet.png` — лист спрайтов (имя можно изменить полем `sheet`);
* `drops/`, `gibs/` — картинки, которые есть только у него.

Старая плоская раскладка (`<name>.json` + `<name>.png` рядом с остальными) тоже читается —
переносить существующих врагов в папки не обязательно, но всё новое пишется в папку.

Если файлов нет или PNG не загрузился, игра берёт встроенное описание и процедурно нарисованный спрайт.
Стартовые PNG (процедурные) лежат рядом — их можно открыть в Aseprite/Photoshop и перерисовать.
В консоли игры `game.exportSheets()` скачает свежие процедурные листы.

## Лист спрайтов

```
кадр 0     кадр 1     кадр 2     кадр 3     кадр 4       ← frames (по горизонтали)
вариант 0  ─────────────────────────────────────────
вариант 1  ─────────────────────────────────────────       ← variants (по вертикали): разная внешность
вариант 2  ─────────────────────────────────────────
```

* Все кадры одного размера `frameW × frameH` пикселей, прозрачный фон.
* Персонаж стоит ногами у нижнего края кадра, по центру. Смотрит на игрока (спрайт всегда повёрнут к камере).
* В мире кадр растягивается до `size` метров (ширина, высота). Крестьянин: 128×160 px → 1.44×1.8 м, воительницы: 132×168 px → 1.49×1.9 м. Стены — 32 px/м, поэтому персонажи чётче фона. Можно рисовать крупнее (например 256×320), `size` при этом не меняется.
* Кадр специально широкий: враги должны читаться как плечистые туши, а не как палки. Тело занимает ~58 % ширины кадра, по бокам остаётся место под оружие и замах.
* Рядом с каждым листом лежит **`<name>_template.png`** — разметка для художника: розовые границы кадров, зелёная линия пола, центральная ось,
  цветные зоны (голова / торс с руками / ноги) и подпись кадра. Процедурный персонаж показан полупрозрачно как ориентир масштаба.
  Верхняя строка с подписью (18 px) в игровом листе не нужна — рисуйте в рамках кадров и сохраняйте как `<name>.png` того же размера без неё
  (или измените `frameH`/`frameW` в JSON под свой размер кадра). `npm run sheets` пересобирает и листы, и шаблоны — он рисует их заново из кода (`sprites.js`), а не пересохраняет уже лежащий PNG, поэтому после смены `frameW`/`frameH` кадры не разъезжаются.
  **Уже существующий `<name>.png` он не трогает** — нарисованный вручную лист не затрётся. Перерисовать процедурные листы заново: `npm run sheets -- --force`.
  Шаблоны (`<name>_template.png`) обновляются всегда: это разметка, а не работа художника.
* Рекомендуется тёмный однопиксельный контур: он читается на любом фоне.

## JSON

```json
{
  "name": "peasant",
  "sheet": "sheet.png",
  "frameW": 128, "frameH": 160, "variants": 3,
  "size": [1.44, 1.8],           // ширина и высота в метрах
  "radius": 0.5,                  // радиус для коллизий и попаданий

  "frames": { "walk0": 0, "walk1": 1, "attack": 2, "pain": 3, "headless": 4 },
  // имя кадра → номер столбца в листе. Имена любые.

  "anims": {
    "idle":     { "frames": ["walk0"] },
    "walk":     { "frames": ["walk0", "walk1"], "fps": 7 },   // зациклена
    "attack":   { "frames": ["attack"] },                      // растягивается на время замаха (windup)
    "pain":     { "frames": ["pain"] },
    "headless": { "frames": ["headless"] },                    // стоит без головы после казни/хедшота
    "die":      { "frames": ["die0", "die1", "die2"] }         // необязательно: падение (0.42 с), иначе спрайт «складывается»
  },

  "stats": {
    "hp": 70, "speed": 3.9, "alertR": 16, "female": false,
    "armor": 0.35,               // 0…0.85 — какую долю урона держит броня (см. «Броня»)
    "melee":  { "range": 2.0, "dmg": 10, "windup": 0.65, "cooldown": 1.3 },
    "ranged": { "range": 26, "burst": 3, "gap": 0.085, "dmg": 7, "aim": 0.45, "cooldown": 1.3, "spread": 0.05 },
    "prefer": [6, 13],           // для стрелков: держаться на такой дистанции
    "lunge": true,               // для ближников: рывок к игроку с 3–7 м
    "flank": [0, 0.9, -0.9, 1.7, -1.7, 3.1]
  },

  "colors": { "body": "#6a4a2a", "legs": "#3a3020", "skin": "#c8956a", "hair": "#2a2018" },
  // цвета груды тела после смерти

  "gibs": "male", "head": "male",  // какой набор кусков и голов использовать: male / female
  "drop": { "items": [{ "sprite": "gib_fork", "w": 0.75 }] }   // что остаётся после него (см. ниже)
}
```

Анимации, которые игра запрашивает: `idle`, `walk`, `attack` (у стрелков — стрельба), `pain`, `headless`, необязательная `die`.
Если анимации нет, берётся `attack`, затем `idle`. Кадров в анимации может быть сколько угодно.

## Заход с флангов — `flank`

Список углов в радианах относительно взгляда игрока, из которого враг случайно выбирает и меняет каждые 2.5–5 с:
`0` — идёт в лоб, `±1.57` — заходит сбоку, `3.1` — за спину. Ближник идёт к точке рядом с игроком под этим углом
(по пути A*, если стена мешает), а когда игрок на него смотрит — уходит по касательной в сторону. Стрелки занимают
позицию на дистанции `prefer` под этим углом и стрейфят.

## Куски тела

Летящие руки, ноги, головы, мясо и предметы рисуются кодом (`src/engine/sprites.js`), но **любой кусок можно
заменить своей картинкой**. Голова после казни берётся из набора `head`. Груда тела строится из цветов `colors` —
на PNG не завязана.

1. `npm run sheets` кладёт образцы всех заменяемых кусков в **`public/gibs/_proc/`** (игрой эта папка не читается).
2. Рисуем поверх нужный и сохраняем в `public/gibs/<имя>.png` — имя файла совпадает с именем куска.
3. Вписываем имя в `public/gibs/index.json`:

```json
["gib_arm", "gib_leg", "gib_skull"]
```

Файла нет, имя незнакомое или картинка не загрузилась — остаётся процедурный кусок, игра не падает.
Пропорции берутся из самой картинки, так что размер кадра может быть любым. Можно указать другое имя файла:

```json
[{ "name": "gib_arm", "file": "ручища.png" }]
```

Заменяются `gib_*` (конечности, мясо, оружие в руках трупа), `head_*` (головы), `pickup_*` и `icon_*` (предметы и
иконки HUD), а также `drop`, `spark`, `rose`, `candle`. Полный список печатает `npm run sheets`.


## Импорт монстров из WAD

```bash
node tools/doom-enemies.mjs <путь/к.wad> [имена через запятую]
```

Достаёт кадры монстра из WAD, складывает лист в `public/enemies/<имя>/sheet.png`, пишет рядом
`enemy.json` (с пустым `drop` — что из него выпадает, дописывается руками) и вписывает врага в `index.json`. Дальше это обычный враг: ставится в редакторе, перерисовывается поверх.

WAD указываете вы — инструмент ничего не скачивает. Подойдёт Freedoom (свободная лицензия, можно
распространять вместе с игрой), собственная копия Doom (только для себя — эти ассеты чужие) или свой PWAD.

Известные монстры: `zombieman`, `sergeant`, `commando`, `imp`, `demon`, `knight`, `baron`, `cacodemon`.
Таблица с их спрайтовыми префиксами, раскладкой кадров и статами — в начале `tools/doom-enemies.mjs`,
правится руками. Здоровье там **не думовское**: в Doom пистолет бьёт на 5–15, здесь на 34, поэтому числа
пересчитаны под оружие игрока с сохранением порядка «кто крепче».

Что импортируется: ходьба (4 кадра), атака, боль, **анимация смерти** (5–7 кадров — своей у процедурных
врагов нет вовсе, только сплющивание). Спрайты берутся с ракурса «спереди»: движок рисует врага
биллбордом, всегда лицом к камере.

Чего в думовских наборах нет: кадров «сдаётся», «бьёт ножом», «присел», «стоит без головы»,
«скачет на одной ноге», «ползёт». Соответствующие механики у такого врага выключаются сами — движок
включает их только при наличии кадров:

| механика | нужен кадр | если кадра нет |
|---|---|---|
| отстрел рук | — | работает всегда (рука вырезается из кадра маской) |
| отстрел ног | `hop0`/`hop1` | нога не отрывается |
| ползёт без обеих ног | `crawl0`/`crawl1` | вторая нога не отрывается |
| обезглавлен, ещё стоит | `headless` | тело падает сразу, фонтан остаётся |
| прячется в укрытии | `crouch` | стоит в укрытии не пригибаясь |
| сдаётся, бьёт ножом | `surrender`, `knife` | отключается через `tactics` |

Дорисуете недостающие кадры в лист и впишете в `frames` — механика включится сама.

Нечеловеческим врагам зоны попадания отключаются по одной: `"parts": { "armL": null, "armR": null }` —
у четвероногой туши руку не отстрелить.

## Что остаётся после врага: `drop`

Вокруг трупа движок больше **ничего не раскидывает сам**: ни случайных рук, ни кусков мяса.
Остаётся только то, что записано врагу в `drop`, — у каждого своё или ничего.

```json
"drop": {
  "items": [
    { "sprite": "fork", "file": "drops/fork.png", "w": 0.75 },
    { "sprite": "gib_hat", "w": 0.38, "chance": 0.5 }
  ],
  "weapon": { "kind": "shotgun", "n": 8, "model": "shotgun", "file": "drops/shotgun.png" }
}
```

* **`items`** — вещи, которые ложатся картинкой рядом с телом: вилы крестьянина, сбитая шляпа,
  гильзы. Лежат как обычные спрайты (всегда лицом к камере) до конца уровня.
  * `file` — PNG из папки врага; без него берётся спрайт с именем `sprite` из общего набора.
  * `w` — ширина в метрах (высота по пропорциям картинки), `n` — сколько штук, `chance` — вероятность (0…1).
  * Разорвало в клочья — вещи разлетаются шире, но выпадают те же самые.
* **`weapon`** — оружие, которое **можно подобрать**: выпадает из рук при смерти или из отрубленной руки
  (один раз: или то, или другое). Висит в воздухе, крутится вокруг своей оси и светится — как в Quake.
  * `kind` — что достаётся игроку: `gun`, `shotgun`, `rocket` (оружие), `ammo`, `shells`, `rockets`, `health`; `n` — сколько.
  * `model` — объёмная модель: `pistol`, `shotgun`, `rocket`, `sword` (у `gun`/`shotgun`/`rocket` подставляется сама).
    `"model": null` — вместо модели плоская картинка `file`/`sprite`.
  * Патроны и аптечки моделей не имеют и остаются плоскими спрайтами.

Не задано ни то, ни другое — после врага не остаётся ничего: у зверя и у чужого монстра
в руках нет ни вил, ни ствола. Так и сделано у бесов, демонов и рыцарей ада.
Старая запись `"stats": { "drop": "gib_fork" }` понимается как `drop.items` из одной вещи.

## Свои куски тела: `gibExtra`, `gibFiles`, `head`

Расчленёнка **общая для всех** — мясо, кости, руки и ноги из одного набора (`public/gibs/`,
см. «Куски тела»). Врагу можно добавить своё, не трогая остальных:

```json
"gibExtra": ["gib_hat"],
"gibFiles": { "gib_arm": "gibs/arm.png", "gib_meat0": "gibs/meat.png" },
"head": "male"
```

* `gibExtra` — что добавляется к общему мясному набору при разрыве в клочья.
* `gibFiles` — свои картинки вместо общих кусков: имя куска → PNG **в папке этого врага**.
  Заменяются поштучно, у других врагов остаётся общий кусок.
* `head` — что отлетает при обезглавливании: `"male"`/`"female"` — человеческая голова из набора,
  имя спрайта — своя картинка, `null` — своей головы нет, и летит череп (`gib_skull`). Так у зверя
  и у импортированных монстров: чужое лицо им не подставляется.

## Смерть: обычная, обезглавливание, в клочья

Движок выбирает одно из трёх:

| исход | когда |
|---|---|
| **в клочья** | крит дробовика, крит взрыва, удар о стену, тяжёлый замах с запасом от половины здоровья, или урон, перебивший здоровье в 1.5 раза |
| **обезглавлен** | попадание в голову (и голова не разорвана критом) |
| **обычная** | во всех остальных случаях |

Крит взрыва — такое же исключение: ракета рвёт в клочья только того, кто стоит в самом эпицентре
и кого волна заведомо добивает, и то в трети случаев (прямое попадание — если боец вдвое слабее
самой ракеты). Пока рвало всех подряд, пул кусков забивался с двух выстрелов, а кадр проседал.

Крит дробовика — это шанс, а не правило: он тем выше, чем кучнее легла дробь, и падает с дистанцией.
В упор разрывает примерно каждого четвёртого, метров с семи — каждого восьмого. Множитель за попадание
в голову сам по себе разрыва не даёт, иначе в упор рвало бы всегда.

## Броня: `stats.armor`

Доля урона, которую съедает шкура или доспех, — от `0` (обычный человек) до `0.85`.
Чем крупнее тварь, тем больше: `sergeant` 0.05, `imp` 0.12, `demon` 0.25, `knight` 0.35,
`baron` 0.45; из встроенных — `guard` 0.15, `brute` 0.35.

Броня никогда не абсолютна, иначе крупного врага было бы нечем убить:

| что пробивает | как |
|---|---|
| в голову | броня держит вдвое хуже |
| тяжёлый замах мечом (`cut`) | броня держит вдвое хуже |
| дробь в упор | `sever` выстрела снимает до 80 % брони — метров с трёх заряд идёт почти целиком |
| крит дробовика, удар о стену | броня не считается вовсе |

Броня уменьшает только то, что доходит до здоровья. Запас зоны (`parts.hp`) она не трогает:
руку и ногу отстреливают с той же скоростью — для этого есть `parts.factor`.

## Оглушение: белое и красное

Оглушений два, и они разные:

* **сбит с ног** (пинок, падение после отброса) — боец шатается несколько секунд, но цел;
* **красный** — боец измотан (здоровье ниже порога «Добивание» из настроек, по умолчанию 10 %, а с оторванной конечностью — вдвое выше):
  он пульсирует красным и **умирает от любого следующего попадания**, чем бы ни ударили.
  Над ним же доступна казнь.

Красным враг становится один раз за бой. Пережил окно (3.6 с) — снова дерётся, но
здоровья у него почти нет.

**Взрыв не оглушает.** Ракета раскидывает бойцов и рвёт им конечности, но упавший
вскакивает и идёт драться дальше. Оглушения не дают ни само попадание (`o.noStagger`),
ни гримаса боли (`o.noFlinch`), ни приземление после подброса, ни удар о стену: флаг
`knockNoStagger` живёт весь полёт — от толчка до полной остановки тела, — и `knockdown`
в это время возвращает бойца сразу в погоню. В полёте спрайт вдобавок не раскачивается:
именно это качание и читалось как «оглушён». Исключение — редкий крит, примерно раз на
тридцать попаданий: тогда боец встаёт «красным» сразу, независимо от здоровья
(`o.mortal`). Причина простая: у эпицентра качались все сразу, и бой превращался в ряд
беспомощных мишеней.

Волна взрыва к тому же выбирает, куда прийтись: конечности вчетверо вероятнее корпуса,
у самого эпицентра достаётся сразу двум зонам. Поэтому от ракеты отлетают руки и ноги,
а не просто убавляется здоровье. Тому, в кого ракета попала телом, волна идёт в корпус
целиком — иначе прямое попадание выходило бы слабее взрыва под ногами (урон по
конечности доходит до здоровья лишь наполовину, см. `pass`).

## Кадры: четырнадцать поз

| кадр | когда показывается |
|---|---|
| `walk0`, `walk1` | ходьба и стойка |
| `attack` | замах / выстрел |
| `pain` | попадание |
| `headless` | обезглавлен, ещё стоит |
| `crouch` | присел в укрытии — попасть труднее |
| `surrender` | руки вверх: сдаётся или притворяется |
| `knife` | удар ножом из положения «руки вверх» |
| `hop0`, `hop1` | **скачет на одной ноге** — вторую отстрелили |
| `crawl0`, `crawl1` | **ползёт** — обеих ног нет |
| `dead` | труп: лежит грудой (спрайт всегда лицом к камере) |
| `deadHeadless` | то же, но без головы |

Анимации `hop` и `crawl` подменяют ходьбу автоматически, как только боец теряет ногу или обе.
Труп после смерти — это кадр `dead` того же листа: перерисовали кадр — изменились все трупы
этого врага. Кровь и лужу движок добавляет сам; что лежит рядом с телом — задаётся в `drop`.

## Зоны попадания: `parts` в JSON

```json
"parts": {
  "head": [0.39, 0.11, 0.61, 0.29],
  "armL": [0.13, 0.19, 0.40, 0.66],
  "armR": [0.60, 0.19, 0.87, 0.66],
  "legL": [0.27, 0.62, 0.51, 1.00],
  "legR": [0.49, 0.62, 0.73, 1.00]
}
```

Доли ширины и высоты кадра, y — сверху вниз. Поле необязательное: без него берутся
значения по умолчанию (`DEFAULT_PARTS` в `src/engine/enemies.js`). **Эти же прямоугольники
пунктиром нарисованы в `<name>_template.png`** — рисуйте конечности внутри них, и попадания
будут считаться правильно, какой бы ни была ваша графика.

Руки при отстреле **вырезаются из кадра** (на срезе движок дорисовывает культю), поэтому рука
должна умещаться в свою зону. Ноги не вырезаются — у них отдельные кадры `hop`/`crawl`.

### Прочность зоны: `hp`, `pass` и `factor`

У каждой зоны свой запас прочности, который тратится **отдельно от здоровья бойца**: рука отваливается,
когда её добили, а не по случайности. Чтобы это настроить, зона записывается объектом:

```json
"parts": {
  "armR": {
    "box": [0.60, 0.19, 0.87, 0.66],
    "hp": 58,
    "pass": 0.8,
    "factor": { "bullet": 1.0, "shotgun": 1.4, "melee": 1.5, "cut": 4.0, "kick": 1.0 }
  }
}
```

* `box` — тот же прямоугольник, что и в короткой записи. Обе формы работают: `[x0,y0,x1,y1]` берёт значения по умолчанию.
* `hp` — запас зоны **в единицах урона** (не в долях здоровья). По умолчанию: голова 55, руки 58, ноги 80 —
  подогнано под оружие игрока (пистолет 34, лёгкий замах 40, тяжёлый 75). У живучего врага зоны крепче:
  множитель `√(HP / 95)`, то есть у рыцаря с 260 HP конечности примерно вдвое крепче, чем у крестьянина с 70.
  Если всё же нужна доля от здоровья — напишите число **не больше 3** (`0.8` = 80 % HP врага).
* `pass` — какая доля урона доходит до самого бойца при попадании в эту зону. По умолчанию: руки `0.8`,
  ноги `0.85`, голова `1.0`.
* `factor` — во сколько раз тип урона эффективнее по этой зоне. Задавать можно частично.

Типы урона: `bullet` (пуля), `shotgun` (дробь), `explosion` (взрыв ракеты), `melee` (лёгкий удар), `cut` (тяжёлый замах),
`kick` (пинок), `generic` (всё прочее).

**Почему `hp` не доля здоровья, а `pass` меньше единицы.** Если бы запас руки равнялся доле HP, а урон уходил
и в руку, и в здоровье одинаково, то к моменту, когда рука добита, боец был бы уже мёртв — оторвать конечность
живому стало бы практически невозможно. Поэтому зона копит полный урон, а до здоровья доходит только часть:
прострелить руку менее смертельно, чем грудь. Это и даёт калечить противника, а не просто убивать.

Всему врагу разом прочность зон крутится множителем `stats.partHp` (по умолчанию `1`).

Как часто конечности отлетают у стражника (95 HP, щит сброшен), по 50 боёв на строку:

| чем бьём | покалечен живым | оторвано на смерти |
|---|---|---|
| лёгкий удар мечом | 96 % | 2 % |
| тяжёлый замах | 64 % | 22 % |
| дробовик | 64 % | 16 % |
| пистолет прицельно | 50 % | 10 % |
| пистолет вразнобой | 6 % | 10 % |

Пистолет вразнобой почти не калечит — попадания расходятся по разным зонам и ни одна не накапливает. Это
задумано: расчленяет тот, кто бьёт кучно или рубит.

Голова — такая же зона: когда её запас кончился, боец **лишается головы**, даже если здоровье ещё осталось.
Если это же попадание его добило, смерть засчитывается как хедшот — с фонтаном, а не обычным падением.
Тяжёлый удар мечом по голове по-прежнему сносит её сразу по шансу `critHead`.

**Ноги отрываются только у того, у кого нарисованы `hop0`/`hop1`** (и `crawl0`/`crawl1` — для второй ноги).
Нет этих кадров в листе — движок ногу не отрывает, иначе боец остался бы стоять на двух ногах с оторванной.
Так сейчас у `knight_hard`: руки ему отрубить можно, ноги — нет, пока не дорисованы кадры.

## Щит — отдельная картинка со стадиями

```json
"shield": { "hits": 6, "frames": 4, "parry": 0.35, "img": "shield.png", "arm": "armR", "w": 0.98, "off": [0.16, 0.44] }
```

* `img` — PNG рядом с листами (`public/enemies/shield.png`), **стадии повреждения лежат в ряд**:
  целый → помятый → треснувший → разбитый. Число стадий — в `frames`.
* `hits` — сколько ударов щит выдерживает. Каждый удар переключает картинку на следующую стадию,
  после последнего удара щит **просто пропадает** (остаются обломки). Руку с собой он не забирает.
* `w` — ширина щита в метрах, высота берётся из пропорций кадра.
* `off` — смещение центра: доля ширины бойца вбок и доля его роста вверх.
* `arm` — какая рука держит щит. **Отстрелили эту руку — щит падает целым** вместе с ней;
  то же при потере обеих рук и при смерти.
* `parry` — вероятность мгновенной контратаки, когда щитом отбили удар мечом.

Щит ловит **только то, что реально им закрыто** (его прямоугольник на кадре). Голова, ноги
и незакрытый бок получают обычный урон — обходить щит можно и нужно.

## Тактика: `stats.tactics`

```json
"tactics": { "cover": 0.8, "surrender": 0.3, "fake": 0.6, "knifeDmg": 26 }
```

* `cover` — вероятность уйти в укрытие, когда здоровья меньше половины. Боец ищет реальный объект
  на уровне и садится за ним, периодически высовываясь.
* `surrender` — вероятность поднять руки.
* `fake` — какая доля сдающихся притворяется: подпускает на 2.5 м и бьёт ножом.
* `knifeDmg` — урон этого удара.

## Щит: `stats.shield`

```json
"shield": { "hp": 150, "parry": 0.35 }
```

Щит принимает на себя весь урон в корпус и в свою зону, пока не наберёт `hp` — потом
разлетается обломками. Попадание в голову или ноги идёт мимо щита. `parry` — вероятность
мгновенной контратаки, когда щитом отбили удар мечом; игрока при этом отталкивает.

## Пост охраны

У врага в уровне можно задать `guardR` (в редакторе — «охраняет пост, радиус»):
боец держит точку появления и не бежит за игроком дальше этого радиуса, а возвращается
и снова караулит. Стрелок при этом всё равно стреляет по цели в пределах дальности оружия.
`0` — гонится по всему уровню. Значение по умолчанию для типа — `stats.guardR`.

Поле `y` у врага задаёт этаж: враг встаёт на ближайшую поверхность под `y + 2.5`.

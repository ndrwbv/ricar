Инструменты

Объекты

Ничего не выбрано. Кликните по объекту или выберите инструмент слева и кликните на карте.

Управление

  • ЛКМ — выбрать / поставить объект инструментом; тянуть — переместить по полу; Alt+тянуть — поднять/опустить.
  • Как в Unity: ПКМ — смотреть, средняя — двигать карту, Alt+ЛКМ — орбита вокруг выбранного, колесо — приблизить к курсору, WASD + Q/E — полёт (Shift быстрее).
  • T — вид сверху ↔ полёт. Сверху: ПКМ/средняя — двигать, колесо — масштаб к курсору.
  • Второй этаж: выберите «этаж» в верхней панели — новые объекты (стены, полы, префабы) встанут на высоту этаж × высота этажа. Высота этажа меняется в свойствах уровня (floorH, по умолчанию 3.2 м). Перекрытие — обычный «Пол / потолок» на нужном этаже, подъём — префаб Лестница. У стены высоту можно задать кнопками «1 эт / 2 эт / 3 эт» в настройках инструмента.
  • PageUp / PageDown — выше/ниже на шаг сетки; стрелки — сдвиг; F — к выбранному.
  • Черчение стен: кликайте точки. Чтобы замкнуть комнату — кликните по жёлтой первой точке или нажмите C (кнопка «Замкнуть» слева). Enter или двойной клик — закончить незамкнутую ломаную, Backspace — убрать последнюю точку, Esc — отменить. Готовые стены сохраняются сразу. Каждый отрезок — отдельная стена, текстуру потом можно сменить.
  • + PNG — своя текстура (тайлится) или спрайт (картинка с прозрачностью, ставится инструментом «Спрайт»).
  • Delete — удалить, Ctrl+D — дублировать, Ctrl+Z / Ctrl+Y — отмена/повтор, Ctrl+S — сохранить, Esc — снять выделение.

Координаты

x — восток, z — юг (вниз экрана), y — высота. У коробок/полов x,z — минимальный угол, w — размер по x, d — по z, h — высота. Текстура тайлится 1 раз на 2 м.

Логика

Триггеры — зоны с действиями (JSON). Правила уровня — реакции на убийства (kill), зачистку тегов (clear), подбор предмета (pickup). Список действий ниже; подробнее в docs/EDITOR.md.
